# Lab 4 — Titanic Dataset Analysis

Simple project for AI Lab (5th Semester) using the Titanic dataset.

## Description

This repository contains a small analysis and model experiment using the `Titanic-Dataset.csv` file. It demonstrates data loading, basic preprocessing, exploratory data analysis, and a simple classifier.

## Files

- `app.py` — main script / notebook runner
- `Titanic-Dataset.csv` — dataset used for the lab
- `requirement.txt` — Python dependencies

## Requirements

Install dependencies from `requirement.txt`:

```bash
pip install -r requirement.txt
```

## Usage

Run the main script:

```bash
python app.py
```
